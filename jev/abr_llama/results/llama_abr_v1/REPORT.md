# Llama-3.2-1B + pointer head：ABR 测试与微调

累计训练 7 轮，按验证 QoE 选中第 **4 轮**。停止原因 `validation_plateau`。最佳模型：`/home/amora/wxh/jev/abr_llama/checkpoints/llama_abr_v1/epoch_04`。

未微调基线是预训练 Llama + 随机初始化 pointer head（seed=666），不是已经训练过的 Kev，也不是生成式零样本问答。微调从完全相同的初始适配器和决策头开始；冻结基座、训练 LoRA 和 pointer head。

55 条训练轨迹包含16条FCC记录和39条Norway日志；7,224个唯一状态，标签由RobustMPC-6产生。batch2×accum8，LoRA lr2e-5，head lr1e-4，FP32主参数、BF16 autocast；各轮保持同一AdamW和OneCycle状态。

优化步骤 3164，累计处理记录 50568，纯训练耗时 40.9 分钟，峰值GPU分配 5.20 GiB。

验证固定30窗口、仅两个采集ID，每轮重复两次。至少4轮、最多12轮，连续3轮未超过+.005的实质改善时早停；最终选择所有候选中观测验证均值最高者。到达轮数上限不代表收敛；重复验证不增加独立来源。
