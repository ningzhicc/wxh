# v4 ABR 初始化400步结果

结论：当前约束+Kev策略在这批开发回放中超过受约束带宽基线，接近离线质量教师；增益明显集中于一个场景，暂不能视为稳定泛化结论。

| 策略 | 平均每场景奖励 | 平均卡顿秒数（不含起播） | 平均证据PSNR dB |
|---|---:|---:|---:|
| bandwidth | 50.84 | 3.354 | 37.01 |
| guarded_bandwidth | 58.94 | 1.793 | 37.80 |
| offline_quality_teacher | 61.64 | 1.197 | 37.85 |
| guarded_model | 61.78 | 1.197 | 37.93 |

- 原始 epoch_08 初始化，400次更新、3200条样本曝光，33.97分钟。无截断／拒绝记录。
- 20场景中相对受约束带宽基线：14胜、3平、3负。
- 最大收益场景贡献总净增益的90.54%；排除该场景，平均每场景仍增加0.284奖励。
- 模型实际调用325次，其余75块按起播／约束规则直接选档；无无效动作回退或预测异常回退。
- 推理中位数105.7毫秒，p95 115.8毫秒；这些耗时未计入传输回放时钟。
- 仍存在网络预测失准和最低档不足的卡顿。教师具有离线PSNR信息，不是长期最优上界；模型略高于教师不代表超越最优策略。
- v3与v4同时改变了约束、监督目标、输入和训练步数，不能把跨版本全部增益归因于某一项改动。当前未对原始未微调 epoch_08 做同协议对照。
- 可将本版保留为系统联调候选，随后完成三步统一入口，并用独立视频与更多网络复核；不需要立即继续堆训练步数。
