# Kev-4B ABR 监督微调与闭环评测

从已发布 Kev-4B 的 LoRA 和 pointer head 继续训练。基座 Qwen3.5-4B-Base 冻结；不是全参数训练，也不是直接训练裸 Qwen。
训练标签由 RobustMPC-6 提供，属于监督行为模仿，本轮没有强化学习或 ABR 概率校准。

训练使用 NetLLM 官方 fcc-train 目录隔离后 55 条轨迹、7,224 个状态，训练两轮，共 904 个优化步骤；有效 batch=16、lr=2e-5。耗时 38.0 分钟。
原始训练/验证集与测试集存在数值重复及同源记录的不同窗口；已按完整原始采集记录隔离后再训练。有效验证集 30 条，使用 30 条选择检查点，仅来自 2 个 FCC 采集 ID，验证来源较少。
目录名 fcc-train 不表示纯 FCC 来源：保留训练轨迹含 16 条 trace_* 与 39 条 Norway 路线日志。因此 Norway3G 的结果不能解读为完全没有接触该采集项目的跨域泛化；同一原始日志及完全相同数值轨迹仍已剔除。详情见 source_overlap.json。

监督模仿不能保证超过规划专家；MPC 可读取未来五块的视频大小，Kev 只读取下一块大小。单种子、单起点结果与会话 bootstrap 不代表重复训练或真实部署的全部不确定性；同一来源的不同窗口可能相关。

测试轨迹仅用于来源与数值去重隔离，未读取测试 QoE 或动作作为训练/选参标签。概率温度为 1，未拟合 ABR 校准。零样本发布版使用其自带温度；温度不改变 argmax，但两个模型的概率不能直接作校准比较。
